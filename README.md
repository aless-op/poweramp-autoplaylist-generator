# Poweramp Autoplaylist Generator
Java application that generates `.m3u8` files readable by Poweramp, designed to remove the need to manually update existing playlists with each new addition to the music library.

[Smart or Dynamic Playlists/Categories & Filters](https://forum.powerampapp.com/ideas/idea/30-smart-or-dynamic-playlistscategories-filters/) is currently one of the highest-voted Poweramp feature requests. This project aims to add that functionality while we wait for the official implementation.

## Progress
The application is currently a terminal-based prototype that supports filtering tracks by metadata and file paths and generating a static `.m3u8` playlist file.

Automatic playlist updating and an Android port with a graphical interface are planned for the future.
